1. コンピュータとは何か

私たちの身の回りにあるコンピュータを知ろう

身の回りのコンピュータ

「コンピュータ」と聞いて思い浮かぶもの...

💻 パソコン
📱 スマートフォン
🎮 ゲーム機
でも実は... 製造現場にはもっと多くのコンピュータがあります

製造現場のコンピュータ

🎛️ PLC
📺 タッチパネル(HMI)
🔍 検査装置
🤖 産業用ロボット
📊 バーコードリーダー
現代の製造現場はコンピュータだらけ

コンピュータの定義

コンピュータとは:

📥 入力
→
⚙️ 処理
→
📤 出力
ポイント: データを入力し、処理（計算）を行い、結果を出力する機械

2. コンピュータの5大装置

コンピュータを構成する5つの主要部品

5大装置の全体像

コンピュータの構造
⌨️
入力装置
→
🧠
制御装置 + 演算装置
→
🖥️
出力装置
↓
💾
記憶装置

5大装置 一覧

⌨️ 入力

データを取り込む

例: キーボード、センサー

🖥️ 出力

結果を出す

例: ディスプレイ、信号灯

🎛️ 制御

全体を指揮

例: CPUの一部

🔢 演算

計算を行う

例: CPUの一部

💾 記憶

データを保存

例: メモリ、SSD

製造現場での具体例①

検査装置の場合:

📷 カメラ 入力装置
→ 画像データ
🖥️ 検査用PC 処理装置
→ 判定結果
✅ 判定表示 出力装置
💾 検査データ保存 記憶装置

製造現場での具体例②

PLCの場合:

📡 センサー 入力装置
→ 信号
🎛️ PLC本体 処理装置
→ 指令
⚡ アクチュエータ 出力装置
ポイント: PLCはプログラマブルロジックコントローラの略。工場の自動制御に必須

3. CPUとメモリ

コンピュータの「頭脳」と「作業台」

CPU（Central Processing Unit）

CPU

役割: コンピュータの「頭脳」

CPU = 制御装置 + 演算装置
  • プログラムの命令を解釈
  • 計算を実行
  • 各装置に指示を出す
例え: CPUは「工場長」のようなもの。指示を出し、計算し、全体を管理する

CPUの性能指標

⏱️ クロック周波数

処理速度（1秒間の処理回数）

3.5GHz = 35億回/秒

🔲 コア数

処理ユニットの数

4〜8 コア

🧵 スレッド数

同時処理できる数

8〜16 スレッド

メモリ（主記憶装置）

RAM

役割: 作業中のデータを一時保存

特徴

  • 高速アクセス
  • 電源を切ると消える（揮発性）
  • 容量は比較的小さい
例え: メモリは「作業台」のようなもの。今使うものを広げておく場所

補助記憶装置

役割: データを長期保存

💿 HDD
  • 大容量
  • 安価
  • 速度は遅め
  • 用途: データ保存
⚡ SSD
  • 高速
  • 衝撃に強い
  • 静音
  • 用途: OS、アプリ
🔌 USBメモリ
  • 持ち運び可能
  • 手軽
  • 小容量
  • 用途: データ移動
例え: 補助記憶装置は「倉庫」のようなもの。使わないものを保管しておく

メモリと補助記憶の関係

📦 補助記憶 HDD/SSD = 倉庫
⟷ 読み込み/保存
📋 メモリ 作業台
⟷ 高速通信
🧠 CPU 工場長
覚え方: 倉庫から作業台に持ってきて、工場長が処理する

4. 様々なコンピュータ

用途に応じた様々なコンピュータの種類

コンピュータの分類

💻 汎用コンピュータ

様々な用途に使える

例: 事務用PC

🏭 産業用PC

耐環境性、長期安定

例: 生産管理端末

🔧 組込みシステム

特定機能に特化

例: PLC、検査装置

🖧 サーバー

複数PCにサービス提供

例: 生産管理サーバー

産業用PC vs 汎用PC

🏭 産業用PC
  • 動作温度: -20〜60℃
  • 寿命: 10年以上
  • 振動耐性: 高い
  • ファンレス: 対応可
  • 価格: 高い
💻 汎用PC
  • 動作温度: 10〜35℃
  • 寿命: 3〜5年
  • 振動耐性: 低い
  • ファンレス: 基本あり
  • 価格: 安い
なぜ高い？ 過酷な環境（高温、振動、粉塵）でも安定動作するため

組込みシステム

定義: 特定の機能を実現するために機器に組み込まれたコンピュータ

🎛️ PLC
🤖 産業用ロボット
📏 計測機器
🚗 AGV（無人搬送車）
ポイント: 組込みシステムは「見えないコンピュータ」。専用機能に最適化されている
