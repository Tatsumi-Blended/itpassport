LANとWANの比較

LAN
  • 範囲: 建物内（狭い）
  • 速度: 高速（1Gbps〜）
  • 構築: 自社で可能
  • 回線: 自前で設置
  • コスト: 初期費用のみ
WAN
  • 範囲: 広域（都市間、国際）
  • 速度: 比較的低速
  • 構築: 通信事業者が必要
  • 回線: 事業者の回線を使用
  • コスト: 月額費用
覚え方: LANは「庭」（自分のもの）、WANは「道路」（公共のもの）

第5章

伝送効率と伝送時間

通信速度に関する計算

伝送効率

回線速度に対する実際の伝送速度の割合

計算式

伝送効率 = 伝送速度 ÷ 回線速度

例: 回線速度100Mbpsで実際に80Mbpsで通信できた場合

伝送効率 = 80Mbps ÷ 100Mbps = 0.8（80%）

注意: 実際の通信では、オーバーヘッド（制御情報など）により100%にはならない

伝送時間

あるデータ量を伝送するのに必要な時間

計算式

伝送時間 = データ量 ÷ 伝送速度

例: 100MBのファイルを80Mbpsで転送する場合

100MB = 100 × 8Mbit = 800Mbit
伝送時間 = 800Mbit ÷ 80Mbps = 10秒

単位注意: B（バイト）とb（ビット）を混同しない！ 1B = 8bit

4つの数字（0〜255）をドットで区切る

インターネット上の「住所」 - 世界中で唯一の値である必要がある（ICANN管理）

現実世界との比較

IPアドレス

住所（どこにあるか）
例: 192.168.1.100

MACアドレス

指紋（機器固有の識別子）
例: 00:1A:2B:3C:4D:5E

ポート番号

部屋番号（サービスの識別）
例: 80, 443, 22

ドメイン名

会社名（覚えやすい名前）
例: google.com

補足: IPアドレスは「最終的な通信相手」を指定、MACアドレスは「次の通信相手」を指定

IPv4とIPv6

IPアドレスのバージョンの違い

IPv4
  • 32ビットで構成
  • 約43億個のアドレス
  • ピリオド区切り・10進数
  • 例: 192.168.1.1
  • 枯渇問題あり
IPv6
  • 128ビットで構成
  • 約340澗個（事実上無限）
  • コロン区切り・16進数
  • 例: 2001:0DB8:1234::5678
  • 枯渇問題を解決
試験ポイント: IPv4は32ビット、IPv6は128ビット（4倍ではなく4倍のビット数）

IPアドレスの種類

グローバルIPアドレス
  • インターネット上で一意
  • 世界中で重複なし
  • 外部からアクセス可能
  • ISPから割り当てられる
プライベートIPアドレス
  • 社内ネットワークで使用
  • 外部からは見えない
  • 自由に割り当て可能
  • インターネット直接接続不可

プライベートIPアドレスの範囲

クラス範囲用途
A10.0.0.0 〜 10.255.255.255大規模組織
B172.16.0.0 〜 172.31.255.255中規模組織
C192.168.0.0 〜 192.168.255.255小規模組織・家庭

NAT（Network Address Translation）

プライベートIPとグローバルIPを相互変換する技術

  ┌─── 社内LAN ───┐                      ┌─ インターネット ─┐
  │               │                      │                │
  │ PC(192.168.1.10)                     │  Webサーバー    │
  │     ↓        │                      │ (203.0.113.50) │
  │ [NAT/ルーター]  │ ─────────────────── │                │
  │ (203.0.113.1) │   グローバルIPで通信   │                │
  │               │                      │                │
  └───────────────┘                      └────────────────┘
         ↑
  プライベートIP → グローバルIPに変換
NATの効果: プライベートIPアドレスしか持たないPCでもインターネット通信が可能に

第10章

IoTとネットワーク

モノのインターネット

IoT（Internet of Things）

あらゆる「モノ」がインターネットに接続される仕組み

  【従来】
  PC・スマホ ────── インターネット

  【IoT時代】
  センサー ─┐
  家電 ─────┼──── インターネット ──── クラウド
  自動車 ───┤                        (データ分析)
  工場機械 ─┘
製造業での活用: 設備の稼働監視、予防保全、品質管理の自動化

IoTの通信技術

BLE（Bluetooth Low Energy）
  • 省電力の無線通信規格
  • ボタン電池1つで数年稼働
  • 通信距離: 約10m
  • 用途: ウェアラブル、ビーコン
LPWA（Low Power Wide Area）
  • 省電力で広範囲の無線通信
  • BLEより通信距離が長い
  • LTEより省電力
  • 通信速度は遅い
技術通信距離消費電力通信速度
BLE短い（〜10m）とても低い低速
LPWA長い（〜数km）低い低速
LTE長い高い高速

エッジコンピューティング

IoT機器の近くにサーバを配置して応答速度を高める技術

  【従来（クラウドのみ）】
  IoT機器 ─────────────── クラウド ─────────────── IoT機器
           長い距離、遅延大

  【エッジコンピューティング】
  IoT機器 ── エッジサーバ ── クラウド ── エッジサーバ ── IoT機器
           近い距離         必要データのみ        近い距離
           高速応答         集約・分析           高速応答

メリット1

低遅延
（即座に応答）

メリット2

帯域節約
（必要なデータだけ送信）

メリット3

信頼性向上
（ネット切断時も動作）

演習3: 伝送時間の計算

問題

200MBのファイルを、伝送効率80%の100Mbps回線で転送する場合、
伝送時間は何秒か？

計算:

実際の伝送速度 = ___ Mbps × ___ = ___ Mbps

データ量（ビット） = ___ MB × 8 = ___ Mbit

伝送時間 = ___ Mbit ÷ ___ Mbps = ___ 秒

解答

実際の伝送速度 = 100Mbps × 0.8 = 80Mbps
データ量 = 200MB × 8 = 1600Mbit
伝送時間 = 1600Mbit ÷ 80Mbps = 20秒

試験対策ポイント

LAN/WAN

  • LAN: 自前の回線、狭い範囲（建物内）
  • WAN: 電気通信事業者の回線、広範囲
  • ISP: インターネット接続サービスプロバイダ

ネットワーク機器

  • ルーター: LANやWANを相互接続、経路選択
  • デフォルトゲートウェイ: 他のネットワークへの出入口
  • スイッチ: MACアドレスで転送先を決定

IPアドレス

  • IPv4: 32ビット / IPv6: 128ビット
  • NAT: プライベートIPとグローバルIPの相互変換
  • DHCP: IPアドレスを自動取得

試験対策ポイント（続き）

プロトコル

  • SMTP: メール送信
  • POP: メール受信（ダウンロード）
  • IMAP: メールをサーバ上で閲覧
  • DNS: ドメイン名とIPアドレスを対応させる仕組み

計算問題

  • 伝送効率 = 伝送速度 ÷ 回線速度
  • 伝送時間 = データ量 ÷ 伝送速度
  • 単位注意: 1B = 8bit

IoT関連

  • BLE: 省電力の近距離無線（Bluetooth）
  • LPWA: 省電力で広範囲の無線通信
  • エッジコンピューティング: IoT機器の近くで処理
