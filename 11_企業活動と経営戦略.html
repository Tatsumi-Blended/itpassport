1. 企業活動の基本

会社の目的

利益を出して継続すること

売上 - コスト = 利益

売上: お客様から得るお金
コスト: 材料費、人件費、設備費など
利益: 残ったお金（これが会社の成長の源泉）

製造業の利益構造

売上高           1,000万円
─ 売上原価        600万円（材料費、労務費、経費）
━━━━━━━━━━━━━━━━━━━
= 売上総利益      400万円（粗利）
─ 販管費          250万円（営業、管理部門のコスト）
━━━━━━━━━━━━━━━━━━━
= 営業利益        150万円

2. 損益分岐点

損益分岐点とは

売上と費用がちょうど等しくなる点（利益ゼロ）

        ↑金額
        │         売上
        │        ／
        │      ／
  損益分岐点→ ●
        │    ／│   総費用
        │  ／  │  ／
        │／    │／
     固定費────┼─────→ 販売量
               │
   この点より右 = 黒字
   この点より左 = 赤字

変動費と固定費

区分定義例
変動費生産量に比例して変動材料費、外注加工費
固定費生産量に関わらず一定減価償却費、固定給

損益分岐点の計算

公式:

損益分岐点売上高 = 固定費 ÷ (1 - 変動費率)
損益分岐点数量 = 固定費 ÷ (単価 - 変動費単価)

限界利益:

限界利益 = 売上 - 変動費
        = 固定費を回収できる金額

演習問題

問題:

  • 製品単価: 150円
  • 材料費（変動費）: 80円
  • 加工費（変動費）: 20円
  • 固定費: 月200万円

月何個売れば黒字か?

演習問題（解答）

限界利益/個 = 150 - 80 - 20 = 50円
損益分岐点数量 = 2,000,000 ÷ 50 = 40,000個

答え: 40,000個以上売れば黒字

改善効果の計算

歩留まり改善の効果:

現状: 歩留まり95%、月産100,000個投入
改善後: 歩留まり96%

良品増加: 100,000 × (0.96 - 0.95) = 1,000個
利益増加: 1,000 × 50円（限界利益）= 50,000円/月

改善活動の効果を金額で示せる!

3. 財務諸表の基本

財務三表

書類内容わかること
貸借対照表（B/S）資産・負債・純資産会社の財産状況
損益計算書（P/L）収益・費用・利益1年間の儲け
キャッシュフロー計算書現金の増減お金の流れ

貸借対照表（B/S）の構造

┌─────────────────┬─────────────────┐
│     資産        │     負債        │
│  （持っている） │  （借りている） │
├─────────────────┤                 │
│ 流動資産        │ 流動負債        │
│ ・現金          │ ・買掛金        │
│ ・売掛金        │ ・短期借入金    │
│ ・在庫          │                 │
├─────────────────┼─────────────────┤
│ 固定資産        │ 固定負債        │
│ ・設備          │ ・長期借入金    │
│ ・建物          │                 │
│ ・土地          ├─────────────────┤
│                 │     純資産      │
│                 │  （自分のお金） │
│                 │ ・資本金        │
│                 │ ・利益剰余金    │
└─────────────────┴─────────────────┘
  資産 = 負債 + 純資産（必ず一致）

製造現場との関連

B/Sと現場のつながり:

  • 在庫 = 原材料、仕掛品、製品の金額
  • 設備 = 製造ラインの価値

現場の改善活動が財務数値に直結!

4. 経営戦略

SWOT分析とは

自社の現状を4つの視点で分析

        内部環境        外部環境
      ┌───────────┬───────────┐
プラス│  強み(S)  │  機会(O)  │
      │ Strengths │Opportunities│
      ├───────────┼───────────┤
マイナス│  弱み(W)  │  脅威(T)  │
      │ Weaknesses│  Threats  │
      └───────────┴───────────┘

製造業のSWOT例

分類例
強み（S）熟練技術者、独自技術、品質
弱み（W）老朽設備、デジタル人材不足
機会（O）DX補助金、海外需要増
脅威（T）人手不足、原材料高騰

クロスSWOT分析

機会(O)脅威(T)
強み(S)積極戦略差別化戦略
弱み(W)改善戦略防衛戦略

例:

  • S×O: 独自技術で海外展開
  • W×O: 補助金でデジタル人材育成
  • S×T: 品質で競合と差別化
  • W×T: 老朽設備の更新でコスト削減

PPM（プロダクト・ポートフォリオ・マネジメント）

          市場成長率
              高
    問題児    │    花形
   Question   │    Star
    Mark      │
──────────────┼──────────────
              │
    負け犬    │  金のなる木
     Dog      │   Cash Cow
              低
        低 ←──────→ 高
           市場シェア

PPMの戦略

分類特徴戦略
花形（Star）高成長・高シェア積極投資
金のなる木（Cash Cow）低成長・高シェア維持・利益回収
問題児（Question Mark）高成長・低シェア選択と集中
負け犬（Dog）低成長・低シェア撤退検討
