第1章

ソフトウェアの分類

1-1. ハードウェアとソフトウェア

区分説明例
ハードウェア 物理的な機器・装置 PC本体、キーボード、モニター、メモリ、HDD
ソフトウェア プログラムやデータ OS、アプリ、ファイル、ドライバー

例え: ハードウェア = 楽器（ピアノ）、ソフトウェア = 楽譜と演奏技術

1-2. ソフトウェアの分類

分類種類説明例
システム
ソフトウェア		 OS（基本ソフト） ハードウェアを管理 Windows、Linux、macOS
ミドルウェア OSとアプリの中間 データベース、Webサーバー
アプリケーション
ソフトウェア		 業務用 特定業務向け 生産管理、CAD
汎用 一般向け Office、ブラウザ

1-3. ソフトウェアの階層構造

┌─────────────────────────────────────────────┐
│      ユーザー（利用者）                      │
└─────────────────────────────────────────────┘
                 ↓ 操作
┌─────────────────────────────────────────────┐
│  アプリケーションソフトウェア               │
│  （Excel、生産管理システムなど）            │
└─────────────────────────────────────────────┘
                 ↓ 依頼
┌─────────────────────────────────────────────┐
│  OS（オペレーティングシステム）             │
│  （Windows、Linux、macOSなど）              │
└─────────────────────────────────────────────┘
                 ↓ 制御

│  ハードウェア                               │
│  （CPU、メモリ、ディスクなど）              │
└─────────────────────────────────────────────┘

OSはアプリとハードウェアをつなぐ「架け橋」

第2章

OSの役割と機能

2-1. OSとは

Operating System（オペレーティングシステム）= 基本ソフトウェア

OSの役割説明
ハードウェア管理CPU、メモリ、ディスクなどを効率的に管理
アプリの実行環境提供アプリケーションが動作する土台を提供
ユーザーインタフェース人間がコンピュータを操作する手段を提供
セキュリティ管理認証、アクセス制御などを実現

2-2. OSの5つの主な機能

機能説明具体例
プロセス管理 プログラムの実行を管理 タスクマネージャー
メモリ管理 メモリの割り当て・解放 仮想メモリ
ファイル管理 データの保存・整理 エクスプローラー
デバイス管理 周辺機器の制御 ドライバー
ユーザー管理 認証・権限管理 ログイン

2-3. マルチタスク

複数のプロセスを順番に切り替えて、同時に処理しているように見せる機能

┌─────────────────────────────────────────────────────┐
│  CPU（1つ）は一度に1つのプロセスしか実行できない     │
└─────────────────────────────────────────────────────┘

時間軸 →
┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐
│A │  │B │  │C │  │A │  │B │  │C │  ...
└──┘  └──┘  └──┘  └──┘  └──┘  └──┘

A = Excelの処理
B = ブラウザの処理
C = 生産管理システムの処理

→ 高速に切り替えるので「同時に動いている」ように見える
ポイント: 実際には同時に処理しているわけではない

2-4. メモリ管理と仮想メモリ

概念説明
物理メモリ 実際に搭載されているRAM（例: 8GB）
仮想メモリ 物理メモリが足りない時、HDDの一部をメモリとして使う
スワップ 物理メモリと仮想メモリ間でデータを入れ替える処理

メモリ不足の症状:

  • PCの動作が遅い
  • アプリが固まる（フリーズ）
  • 「メモリが不足しています」エラー

2-5. BIOS

Basic Input Output System

特徴説明
役割PCの起動設定を行うソフトウェア
起動タイミングOSより先に起動する
機能接続されている機器をチェック
格納場所マザーボード上のROMチップ
PC電源ON → BIOS起動 → 機器チェック → OS起動 → 使用可能

2-6. 主なOSの種類

OS名特徴主な用途
WindowsGUI充実、普及率高い事務PC、HMI端末
Linux無料、安定、サーバー向きサーバー、組込み機器
macOSApple製PC用デザイン、開発
iOSiPhone/iPad用モバイル端末
Androidスマートフォン用タブレット端末
リアルタイムOS時間制約を保証PLC、ロボット制御

データのまとまりを「ファイル」として扱い、管理しやすくする機能

3-4. パス（Path）とは

ファイルやディレクトリの場所を示す文字列（住所）

基点として記述		 ./高解像度/みかん.jpg
..\図面\製品A.pdf

3-5. パス指定の4つのルール

ルール説明例
1. 区切り文字 ディレクトリやファイルは「/」で区切る
（Windowsは「\」も可）		 /画像/高解像度/
2. ルート省略 パスの始まりが「/」の時は
ルートディレクトリが省略されている		 /画像 = ルート/画像
3. カレント表記 カレントディレクトリは「.」で表す ./ファイル.txt
4. 親ディレクトリ 1階層上のディレクトリは「..」で表す ../音楽/曲名.mp3

3-6. パス指定の具体例

現在地（カレントディレクトリ）: /製造部/手順書/

【目的2】2024年01月.xlsxにアクセス（/品質管理部/検査記録/2024年01月.xlsx）

  相対パス: ../../品質管理部/検査記録/2024年01月.xlsx
                ↑ 2つ上（ルート）まで移動

3-7. 拡張子

ファイルの種類を示す末尾の文字

拡張子種類拡張子種類
.txtテキストファイル.pdfPDF文書
.xlsxExcelファイル.docxWordファイル
.jpg/.png画像ファイル.mp4動画ファイル

注意: 拡張子を変えてもファイルの中身は変わらない

3-8. アクセス権限

誰が何をできるかの制御

権限できること
フルコントロール読み取り、書き込み、削除、権限変更すべて可能
変更読み取り、書き込み、削除が可能
読み取り閲覧のみ可能（編集不可）
なしアクセス不可

例: 最新版図面フォルダは一般社員「読み取り」、設計担当「変更」

第4章

バックアップ

4-1. バックアップとは

通常使用している補助記憶装置とは別の装置にデータの複製を取っておくこと

目的説明
データ保護障害や誤操作からデータを守る
災害対策火災、地震などからの復旧
ランサムウェア対策暗号化されてもバックアップから復旧

4-2. 3種類のバックアップ

種類バックアップ対象特徴
フルバックアップ すべてのデータ 作業が簡易
バックアップ時間が長い
復旧が簡単
差分バックアップ フルバックアップ以降の
追加・変更分		 復旧時はフル+差分の
2つのファイルが必要
増分バックアップ 前回のバックアップ以降の
追加・変更分のみ		 最も時間が短い
復旧が複雑（全ファイル必要）

4-3. バックアップの比較図

日曜日: フルバックアップ [ABCDE] ← 全データ

【差分バックアップの場合】
月曜日: 差分 [F]        ← 日曜日以降の追加分
火曜日: 差分 [FG]       ← 日曜日以降の追加分（累積）
水曜日: 差分 [FGH]      ← 日曜日以降の追加分（累積）
復旧時: フル + 最新の差分 = 2ファイル必要

【増分バックアップの場合】
月曜日: 増分 [F]        ← 日曜日以降の追加分
火曜日: 増分 [G]        ← 月曜日以降の追加分
水曜日: 増分 [H]        ← 火曜日以降の追加分
復旧時: フル + 全ての増分 = 4ファイル必要

4-4. 関連用語の違い

用語目的タイミング
レプリケーション システムの継続（可用性確保） 即時同期（自動・リアルタイム）
バックアップ データの保護（復旧用） 定期的（1日1回など）
アーカイブ データの長期保管 数カ月〜年に1回程度

レプリケーション: 主に冗長化目的でリアルタイムにコピーを維持
アーカイブ: 法令対応や履歴保存のための長期保管

第5章

表計算ソフト

5-1. 表計算ソフトの基本用語

用語説明
ワークシート作業スペース全体（1つの表）
セル1つ1つのマス目（データを入力する場所）
行横方向の並び（1, 2, 3...）
列縦方向の並び（A, B, C...）
セル番地セルの位置を示す（例: A2, B3, C10）

5-2. セル番地の読み方

      A列   B列   C列   D列
    ┌─────┬─────┬─────┬─────┐
 1行│ A1  │ B1  │ C1  │ D1  │
    ├─────┼─────┼─────┼─────┤
 2行│ A2  │ B2  │ C2  │ D2  │
    ├─────┼─────┼─────┼─────┤
 3行│ A3  │ B3  │ C3  │ D3  │
    └─────┴─────┴─────┴─────┘

セル番地 = 列のアルファベット + 行の番号
例: B2 = B列の2行目のセル

5-3. セル範囲の指定

長方形エリアに含まれるセルの集まりを指定

記法説明例
: (コロン) 範囲の始まりと終わりを指定 B2:D2（B2からD2まで） 
      A列   B列   C列   D列
    ┌─────┬─────┬─────┬─────┐
 1行│     │ 1月 │ 2月 │ 3月 │
    ├─────┼─────┼─────┼─────┤
 2行│売上 │ 100 │ 150 │ 200 │ ← B2:D2 の範囲
    └─────┴─────┴─────┴─────┘

合計(B2:D2) → 100 + 150 + 200 = 450

5-4. 主な関数

関数機能使用例結果
SUM合計=SUM(B2:D2)450
AVERAGE平均=AVERAGE(B2:D2)150
MAX最大値=MAX(B2:D2)200
MIN最小値=MIN(B2:D2)100
COUNT個数=COUNT(B2:D2)3
IF条件分岐=IF(B2>100,"OK","NG")NG

5-5. 複写（コピー）と参照

あるセルの内容を別のセルにコピーすること

種類説明記法
相対参照 複写時にセル番地が自動調整される B2
絶対参照 複写時にセル番地を固定する $B$2

$（ドル記号）で列や行を固定

5-6. 絶対参照の詳細

指定説明コピー時の動作
B2 相対参照（固定なし） 列も行も変わる
$B2 列を固定 列はB固定、行は変わる
B$2 行を固定 列は変わる、行は2固定
$B$2 列と行の両方を固定 常にB2を参照

例: 税率セル（$A$1）を常に参照したい場合は絶対参照を使用

第7章

オープンソースソフトウェア（OSS）

7-1. OSSとは

ソースコードが公開されていて、改良や再配布を自由に行えるソフトウェア

比較プロプライエタリOSS
ソースコード 非公開 公開
費用 有料（ライセンス料） 基本無料
カスタマイズ 制限あり 自由に改良可能
例 Windows、Office Linux、Firefox

7-2. OSSの具体例

用途OSS名代替する商用製品
OSLinuxWindows
WebサーバーApacheIIS
データベースMySQL、PostgreSQLOracle、SQL Server
WebブラウザFirefox―
メールソフトThunderbirdOutlook
オフィスソフトLibreOfficeMicrosoft Office

7-3. OSSの4つの特徴

特徴説明
1. ソースコード公開 誰でもソースコードを見て、自由に改良できる
2. 有料販売可能 付加価値（サポートなど）をつけて販売できる
3. 著作権あり 権利フリーではない（著作者の権利は保護される）
4. 再配布ルールあり ライセンスに従って再配布する必要がある
注意: 「無料」≠「何でも自由」。ライセンス条件の確認が必要

7-4. ライセンスの種類

種類説明例
プロプライエタリ 有料、ソース非公開 Windows、Office、Adobe製品
オープンソース ソース公開、改良・再配布自由 Linux、Firefox、LibreOffice
フリーウェア 無料、ソース非公開 各種フリーソフト
シェアウェア 試用後有料 一部の専門ソフト

7-5. ライセンス違反に注意

よくある違反リスク
1ライセンスを複数PCで使用
  • 法的問題（著作権法違反）
  • セキュリティリスク（更新不可）
  • 監査時の問題（罰金など）
会社のソフトを自宅PCにインストール
ライセンス切れのまま使用継続

対策: ライセンス管理台帳を作成し、定期的に確認する

演習2: パスの理解

現在地: C:\製造部\手順書\

目的ファイル: C:\製造部\図面\製品A.pdf

演習3: バックアップの選択

以下の状況に適したバックアップ方式を選んでください:

状況適した方式理由
毎日大量のデータが追加される
復旧を最も簡単にしたい
バックアップ時間を最短にしたい

演習3: 解答

状況適した方式理由
毎日大量のデータが追加される 増分バックアップ 追加分のみでバックアップ時間を短縮
復旧を最も簡単にしたい フルバックアップ 1ファイルから復旧可能
バックアップ時間を最短にしたい 増分バックアップ 前回からの追加分のみ

演習4: 表計算の参照

以下の数式をB2からD2にコピーした時、参照先はどうなる？

元の数式（B2）C2にコピーD2にコピー
=A1*B1
=$A$1*B1
=A$1*$B1

演習4: 解答

元の数式（B2）C2にコピーD2にコピー
=A1*B1 =B1*C1 =C1*D1
=$A$1*B1 =$A$1*C1 =$A$1*D1
=A$1*$B1 =B$1*$B1 =C$1*$B1

$がついた列/行は固定され、ついていない部分は移動に合わせて変化
